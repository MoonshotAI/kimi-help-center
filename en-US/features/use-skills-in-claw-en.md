# Using Skills in Kimi Claw

Kimi Claw is an AI assistant with unique personality and long-term memory capabilities that can run scheduled tasks in the background, collaborate across platforms, maintain context memory, and automate tedious work like information aggregation, monitoring, and notifications.

## Getting and managing skills

### Downloading skills from Kimi

You can download official or custom skills from the Kimi platform to your local Claw:

1. Open Kimi Claw and navigate to the **Skills** section.
2. Browse the skill list, select the skill you need, and choose **Download to Claw**.
3. After downloading, you can invoke it directly in Claw.

<Callout type="info">
When skills are updated, local versions won't be automatically overwritten. To get the latest content, please manually re-download.
</Callout>

### Syncing skills from Kimi Agent

If you have already added skills in Kimi Agent (web version), Kimi Claw can directly sync and display these skills without requiring reconfiguration.

When Kimi Claw detects that skill versions are inconsistent between the two platforms, it will display a **Update Required** prompt next to the skill. Click to sync to the latest version.

### Using the Clawhub skill library

Kimi Claw includes a built-in **Clawhub Skill Library** featuring verified, high-quality skills covering various common work scenarios:

- **Information Organization**: News summaries, competitor comparisons, meeting minutes templates.
- **Analysis Work**: Stock and industry review, data interpretation, risk identification.
- **Workflow Management**: Complete processes from requirement breakdown to result delivery.

Enter the skill library, browse or search for skills that fit your work scenario, and click to install.

## Invoking skills

In Kimi Claw's input box, there are three ways to invoke skills, consistent with the web version:

- Type `/` to select a skill from the popup list.
- Click the **+** button next to the input box and select from the menu.
- Type the skill name directly.

<Callout type="warning">
The skill entry in third-party OpenClaw, local Kimi Claw, and desktop Kimi Claw is currently unavailable.
</Callout>

## Teaching Claw your working method

Beyond using pre-made skills, you can "teach" Claw the experience and methods you've accumulated, so it works long-term according to your habits. There are three main ways:

**Give processes**: Tell Claw the specific steps you take when handling a certain type of task.

**Give standards**: Tell Claw what you value most—accuracy, speed, feasibility, or risk control.

**Give templates**: Tell Claw your desired output format. For example, if your work daily report structure is "What I did today → Problems encountered → Tomorrow's plan → Need assistance", tell Claw directly, and it will organize future reports in this format.

### Case study

Suppose you're a product manager who needs Kimi Claw to help you review user feedback every week. You can teach Claw this way:

1. **Process**: "Every Monday, after collecting user feedback, first categorize by feature module, then tag priority levels (P0-P3), and finally extract high-frequency issues."

2. **Standards**: "I value feedback authenticity and feasibility most, so exclude duplicate opinions and keep only feedback with specific use-case descriptions."

3. **Template**: "Output format: Feature Module | Feedback Content | Priority | User Count | Suggested Solution"

Once you tell Claw "Help me organize this week's user feedback," it will automatically process according to these standards without you needing to repeat explanations each time.

<Callout type="tip">
Through the combination of skills and customized working methods, Kimi Claw can complete tasks faster and more accurately, continuously generating results that match your habits.
</Callout>

## Mobile usage notes

When using skills on mobile, be aware of the following limitations:

- If you have added skills on the web version, the plus menu will show a skill entry. Clicking will insert the skill as text in the input box.
- If skills are not added on the web version, the plus menu on mobile won't show the skill entry.
- If the conversation history contains skill-generated content, a prompt will appear: **Skill generated, currently only supported on Kimi web platform**.

We recommend completing some skill management operations (such as creating, editing, deleting) on the web platform, with mobile primarily used for invoking existing skills.
