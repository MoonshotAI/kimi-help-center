# Kimi Work Overview

Kimi Work is a general-purpose local Agent for knowledge workers, available in the "Work" mode of the Kimi desktop client (Mac / Windows).

It brings the Agent capabilities proven by Kimi Code in engineering scenarios into the desktop interactions familiar to everyday knowledge workers: you don't need to open a terminal, write commands, or configure environments. Just describe your goal in natural language, and Kimi Work breaks down the task, runs steps in parallel, calls tools, uses the browser, creates and organizes folders, and delivers work products such as documents, spreadsheets, and slide decks — all on your own computer.

Kimi Code serves developers who write code; Kimi Work serves knowledge workers, mainly covering everyday scenarios like moving information around, organizing files, analyzing data, and producing reports.

## Core Capabilities

- **Local Agent kernel**: Powered by Kimi Code as its kernel, providing local Agent fundamentals including installing and using Skills and running scheduled tasks.
- **Professional Skills**: Inherits the professional Skills of the online Kimi Agent, such as website building and PPT creation, and also supports recommending third-party Skills and uploading local Skills.
- **Plugins and professional databases**: Use external apps and services within Kimi, such as Canva, Notion, and WPS, and connect to professional databases in finance, research, law, and other fields.
- **Kimi WebBridge**: A built-in browser-operation solution that uses a browser just like a person would.
- **Agent Swarm**: Based on task complexity, autonomously assembles a team of up to 300 sub-agents to handle more complex, longer-running tasks.
- **Long-horizon task execution**: Powered by the long-horizon task execution of the Kimi K2.6 model, supporting 13 hours of continuous coding, 300 sub-agents working in parallel, and over 4,000 autonomous tool calls.

## Interface and Interaction

- The client has two modes, "Work" and "Chat". The Work-mode sidebar includes: New Task, Skills, Scheduled Tasks, WebBridge, Projects, and Chat.
- Type "/" in the input box to quickly use Skills, and "@" to add context.
- Permission control is provided, and you can choose how to authorize:
  - **Request permission**: ask for authorization before acting
  - **Allow all**: run directly without asking for authorization
- Switch between two execution modes: "Agent" and "Agent Swarm".

## Version Notes

Kimi Work launched on June 3, 2026 and is currently in Beta with frequent iteration. It has progressively added features such as file preview, automatic draft saving, Goal mode, and the Plugin Center. The current testing focus is on task decomposition, multi-agent parallelism, tool calling, browser operation, local file handling, and long deliverable generation; execution stability, delivery quality, and user experience will keep improving based on feedback from beta users.
