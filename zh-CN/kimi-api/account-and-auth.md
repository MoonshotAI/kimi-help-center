# 账号与认证

以下是 Kimi 开放平台开发者账号与认证相关的常见问题。

## 如何进行个人以及企业认证？

### 个人认证

请登录 [用户中心](https://platform.kimi.com/console/auth) 进行实名认证。

### 企业认证

请登录 [用户中心](https://platform.kimi.com/console/auth) 进行企业认证，请提前准备企业相关信息：

- 企业名称
- 与企业名称相同的银行账号
- 统一社会信用代码

平台会向您公司账户打款随机金额，用于验证企业信息。请联系贵公司财务确认，填入来自北京月之暗面科技有限公司的打款金额，金额匹配成功后，企业认证通过。

<Callout type="info">
认证成功后会为您赠送 15 元代金券，可用于支持该代金券的模型（Kimi K3 不支持使用新用户代金券）。
</Callout>

## 个人认证和企业认证有什么区别？

| 对比项 | 个人认证 | 企业认证 |
| --- | --- | --- |
| 发票类型 | 个人普通发票/公司抬头发票 | 企业认证主体抬头发票 |
| 速率限制 | 标准 | 可申请更高配额 |
| 商务合作 | — | 支持签署合同 |
| 企业折扣 | — | 可申请 |
| 技术支持 | 标准 | 优先支持 |

## 是否支持变更认证类型？

- 认证状态仅支持个人认证变更为企业认证，变更成功后，账号充值请按照企业账号充值的指引操作。
- 不支持企业认证账号变更为个人认证。

<Callout type="info">
注意：个人转企业后，原有余额和用量数据将保留。
</Callout>

## 完成认证有什么好处？

- **更高速率限制**：认证用户可获得更高的 API 调用速率。
- **完整功能**：部分高级功能可能仅对认证用户开放。
- **发票支持**：认证后可正常开具发票。
- **技术支持**：认证用户享有更高优先级的技术支持。
- **新用户福利**：国内注册并完成认证的用户可获赠 15 元代金券。

## 是否支持账号密码登录？

支持账号密码设置。密码设置成功后，可以通过手机号/密码登录和账号名/密码登录。设置入口：[账号密码设置](https://platform.kimi.com/profile)。

## 是否支持手机号换绑？

支持手机号换绑。换绑的目标手机号需未注册过 Kimi 开放平台或 Kimi 智能助手。

## 是否支持账号注销？

不支持账号注销。

## 账号被封了如何申诉？

如果你的 API 账号因违规被封禁：

1. 发送邮件至 **api-service@moonshot.ai**，主题注明「API 账号申诉」。
2. 邮件中提供你的账号信息（注册手机号/邮箱）和申诉说明。
3. 平台将在 1-3 个工作日内审核并回复。
