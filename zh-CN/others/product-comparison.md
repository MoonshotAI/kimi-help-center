# Kimi、Kimi Work、Kimi Code、Kimi Claw 有什么区别？该用哪个？

Kimi 既有开箱即用的在线助手，也有几款面向不同人群和场景的产品。它们共用 Kimi 的核心能力，区别主要在于**在哪使用、面向谁、擅长什么**。

## 一图看懂区别

| 产品 | 是什么 | 适合谁 / 场景 | 在哪使用 |
|---|---|---|---|
| **Kimi**（网页 / App） | 在线 AI 助手，对话与 Agent 一体 | 日常问答、写作、搜索、建站 / PPT / 文档表格、深度研究等 | 网页、手机 App |
| **Kimi Work** | 面向知识工作者的**本地 Agent**（桌面端） | 处理电脑本地文件、跨桌面应用自动化、长任务交付 | Mac / Windows 客户端 |
| **Kimi Code** | 面向**开发者**的编程助手套件 | 写代码、维护代码库 | 命令行（CLI）、VS Code 插件 |
| **Kimi Claw** | **零部署云端自动化**平台 | 7×24 常驻云端自动化、接入飞书 / 微信等的机器人 | 云端（无需服务器） |

## 该用哪个

- **只是日常对话、写作、搜索，或让 Kimi 帮你建网站、做 PPT 和表格、做深度研究** → 直接用 **Kimi**（网页 / App）即可。
- **需要 Kimi 读写你电脑上的本地文件、跨多个桌面应用自动化、跑长时间任务** → 用 **Kimi Work**（桌面端）。
- **你是开发者，主要用于写代码、维护项目** → 用 **Kimi Code**。
- **想要一个常驻云端、自动运行、还能接入飞书 / 微信等平台的机器人** → 用 **Kimi Claw**。

<Callout type="tip">
Kimi 的在线体验已经把「对话」和「Agent」合并——你无需在两者之间切换。Kimi Work 桌面端内部还分「Work」（面向交付物的 Agent 模式）和「Chat」（快速对话）两种模式。
</Callout>

## 该开哪个会员

会员权益按你的 Kimi 账号计算。所有会员功能（对话、Agent、深度研究、Kimi Code 等）**共享同一个额度池**；其中 Kimi Code 另有 5 小时 / 周限额，仅作用于 Kimi Code。具体套餐与价格请见[会员订阅页](/membership/membership-pricing)。

如果你主要是**日常使用 + 偶尔做任务**，选择合适档位的 Kimi 会员即可覆盖网页 / App / Kimi Work 的大部分场景；**高频写代码**的开发者可额外关注 Kimi Code 的权益。
