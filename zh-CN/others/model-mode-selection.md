# 怎么选：K2.6 / K3 / K3 集群、思考强度与 Agent

Kimi 会根据你的问题自主判断是否联网，你无需手动切换。真正需要你选择的是**模型**和**思考强度**；执行复杂任务时还会用到 **Agent** 与 **Agent 集群**。

## 三档模型

在输入框上方的模型切换按钮，可以选择：

| 模型 | 思考强度 | 擅长场景 | 额度 |
|---|---|---|---|
| **K2.6** | 标准 / 进阶 | 快速对话与问答，响应更快 | **会话中不消耗会员额度** |
| **K3** | 标准 / 进阶 / 极致 | 对话与 Agent 任务，综合能力最强 | 按额度计费 |
| **K3 集群** | 标准 / 进阶 / 极致 | 海量搜索、批量处理，一次性完成大规模任务 | 按额度计费 |

- **K3** 可端到端产出可编辑文档（如 `.pptx`、`.docx`、`.xlsx`、`.pdf`）；**K2.6** 偏快速问答，仅输出文本内容（如 PPT 大纲、Word 正文、代码等）。
- 如需**图片 / 视频 / 音频生成**，点击「+」→ 插件，选择对应功能后在 **K3** 中使用。

<Callout type="info">
K2.6 免费不消耗额度，仅指**会话入口**（输入框上方模型选择器）中的使用。在 **Kimi Work** 中作为 K2.6 Agent 使用时，仍会消耗会员额度。
</Callout>

## 思考强度：标准 / 进阶 / 极致

思考强度越高，模型推理越充分、通常更聪明，但**占用的 token 也越多**。

- 追求**速度、节省额度** → 选 **标准**；
- 需要**更强推理**（复杂分析、难题） → 选 **进阶** 或 **极致**（K3 / K3 集群支持极致）。

## Agent 与 Agent 集群

- **通用 Agent**：自动规划并完成任务，支持网站生成、PPT 制作、深度研究、文档和表格处理等。
- **Agent 集群**：支持超过 4,000 次并行工具调用，可自主调度多达 300 个子智能体（Sub-agents）并行处理，适合**海量搜索、长文写作、批量处理**等大规模任务。

## 按场景怎么选

- **快速问答、日常对话** → K2.6（会话中不消耗额度）。
- **复杂对话、写文档 / 做 PPT 和表格 / 多步任务** → K3。
- **海量搜索、批量处理、超长文写作** → K3 集群。
- **想省额度** → 用 K2.6，或把思考强度调为「标准」。

## 常见问题

### 现在没有「思考模式」了吗？
Kimi 已把「对话」和「Agent」合并为一体，不再单独区分模式。「思考」现在通过**选择模型和思考强度**来体现——例如用 K3 并调高思考强度，即可获得更充分的推理。

### K2.6 和 K3 有什么区别？
K2.6 偏快速问答、响应更快，会话中不消耗会员额度；K3 综合能力最强，擅长复杂对话与 Agent 任务，可端到端产出可编辑文档，按额度计费。

### K3 和 K3 集群有什么区别？
K3 适合一般的对话与 Agent 任务；K3 集群通过大规模并行（数千次工具调用、数百个子智能体）处理**海量搜索、批量、超长文**等大规模任务。

### 单次能处理多长的内容？
K2.6 单轮上下文约 128K token（约 5-6 万汉字）；K3 提供 100 万 token 上下文（需最高档会员权益）。详见[会话超 20 万字了怎么办？](/others/chat-issues)。
