# 在 Kimi Claw 中使用技能（Skills）

Kimi Claw 是一个具备独特个性与长期记忆能力的 AI 助手，它能在后台定时运行、跨平台协作、长期记忆上下文，把信息汇总、监控、通知等繁琐工作自动化。

## 获取和管理技能（Skills）

### 从 Kimi 下载技能（Skills）

你可以把 Kimi 平台上的官方技能或自定义技能下载到 Claw 本地：

1. 打开 Kimi Claw，进入 **技能** 入口。
2. 浏览技能列表，点击你需要的技能，选择 **下载到 Claw**。
3. 下载后即可在 Claw 中直接调用。

<Callout type="info">
技能有更新时，不会自动覆盖本地版本。如需获取最新内容，请手动重新下载。
</Callout>

### 同步 Kimi Agent 中的技能（Skills）

如果你已经在 Kimi 网页端的 Agent 模式中添加过技能，Claw 可以直接同步显示这些技能，无需重新配置。

当 Claw 检测到两端技能版本不一致时，会在技能旁显示 **需要更新** 提示，点击即可同步到最新版本。

### 使用 Clawhub 技能库

Kimi Claw 内置了 **Clawhub 技能库**，收录了经过验证的高质量技能，涵盖多种常见工作场景：

- **信息整理**：新闻汇总、竞品对比、会议纪要模板化
- **分析工作**：股票与行业梳理、数据解读、风险点提取
- **工作流管理**：从需求拆解到结果输出的完整流程

进入技能库，浏览或搜索适合你工作场景的技能，点击即可安装。

## 调用技能（Skills）

在 Claw 的输入框中，支持以下三种方式调用技能，与网页端一致：

- 输入 `/` 从弹出列表中选择技能
- 点击输入框旁的 **＋** 按钮，从菜单中选择
- 直接输入技能名称

<Callout type="warning">
第三方 OpenClaw、本地端 Claw 以及桌面 Claw 的技能入口暂不可用。
</Callout>

### 示例

假设你每天需要汇总行业动态，但每次都要重复说明格式：

1. 在输入框输入 `/skill-creator`，告诉 Kimi："帮我做市场信息汇总时，先筛选权威来源，然后按'机会 / 风险 / 数据'三个维度整理，最后给出一个行动建议。"
2. Kimi 会把这套流程生成为一个自定义技能。

## 让 Claw 学习你的工作方式

除了使用现成技能，你还可以把自己积累的经验和方法"教"给 Claw，让它长期按你的习惯工作。主要有三种方式：

**给流程**：告诉 Claw 你处理某类任务的具体步骤。

**给标准**：告诉 Claw 你最看重什么——准确性、速度、可执行性，还是风险控制。

**给模板**：告诉 Claw 你希望的输出格式。比如你写工作日报的结构是"今天做了什么 → 遇到的问题 → 明天计划 → 需要协助"，直接告诉 Claw，它以后就会按这个格式帮你整理。

### 案例

假设你是产品经理，需要 Claw 帮你每周梳理用户反馈。你可以这样教 Claw：

1. **流程**："每周一收集用户反馈后，先按功能模块分类，然后标注优先级（P0-P3），最后提取高频问题。"

2. **标准**："我最看重反馈的真实性和可行性，所以要排除重复意见，只保留有具体场景描述的反馈。"

3. **模板**："输出格式：功能模块 | 反馈内容 | 优先级 | 用户数量 | 建议方案"

这样一旦你告诉 Claw"帮我整理这周的用户反馈"，它就会自动按照这套规范处理，无需每次重复说明。

## 移动端使用说明

在移动端使用技能时，有以下限制需要注意：

- 如果你在网页端已添加技能，加号菜单会显示技能入口，点击后以文本形式插入输入框。
- 如果网页端没有添加技能，移动端的加号菜单中不会显示技能入口。
- 如果对话历史中有技能生成的内容，会显示提示：**技能已生成，暂仅支持前往 Kimi 网页端添加**。

部分技能管理操作（如创建、编辑、删除）建议在网页端完成，移动端主要用于调用已有技能。
