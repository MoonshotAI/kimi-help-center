# 加油包：额外用量购买

订阅额度用尽后，可用**加油包（Extra Usage）**余额继续发起请求，无需等待额度刷新。仅订阅会员可开启，且余额在**网页版、浏览器插件、桌面端、移动端与 Kimi Code 之间共享**（充值一次，全端通用）。完整条款见 [加油包充值协议](https://www.kimi.com/user/agreement/extra-usage-rules-cn)。

## 充值入口

- **从主站充值**：进入 Kimi [订阅页面](https://www.kimi.com/membership/subscription?tab=quota)，滚动至页面底部的「额度加油包」模块 → 选择充值金额 → 完成支付。
- **从 Kimi Code 控制台充值**：当**周额度或 5 小时额度任意一项消耗超过 80%** 时，进度条卡片会出现【加油包购买】按钮，点击即可跳转至 Kimi 订阅页完成购买。

## 开启与管理

- 打开「额度加油包」开关后，当订阅额度用尽时，系统会自动从加油包余额中扣减。
- 可随时关闭加油包：关闭后余额保留在账户中，系统暂停从加油包扣减，重新开启即可继续使用。开关管理目前仅网页版支持，桌面端和手机 App 暂不支持。
- 加油包余额仅限个人账户使用，不与团队或企业账户共享。
- 点击模块的「设置」可开启**每月消费上限**（默认关闭）：设置金额须高于单笔最低充值金额（25 元）；当月消费达到上限后，系统将暂停当月继续消耗加油包额度。进度条则实时显示本月加油包的消耗情况，可前往 [我的额度](https://www.kimi.com/membership/subscription?tab=quota) 查看余额与消耗明细。

## 计费与规则

- **计费**：按实际用量扣费——读取与生成的内容越多、任务越复杂，花费越高；余额以人民币显示，费率以平台展示为准。加油包价格近似于 [Kimi 开放平台](https://platform.kimi.com) 的官方 API 价格；用量较大时，升级订阅通常更划算。
- **消耗优先级**：先扣订阅等限时额度，**加油包最后扣**，作为兜底补充；开启后即使订阅额度用尽，也能无缝消耗加油包余额，任务不中断、不报错。
- **限额控制**：可在设置中开启「每月消费上限」，为加油包设定本月最多可花费的金额；不开启则不限额。
- **有效期与叠加**：余额不过期、可叠加；订阅失效后余额仍可继续消费，但失效期间无法再充值，需重新开通订阅后才能充值。
- **退款**：一般不可退款、转让或兑现。

<Callout type="info">
计费示例（仅供感受量级，实际以平台为准）：一次简单请求（如「推荐一首摇滚歌曲」）约 **0.03 元**；一次复杂的多步任务（如「规划一周成都到川西的自驾行程」）约 **1.6 元**。充值限制：单次最低 25 元，每日最多 10 次、累计 3,000 元，余额上限 10,000 元。
</Callout>

## 查询用量

- **Kimi 网页 / App**：设置 → 订阅和发票 → [我的额度](https://www.kimi.com/membership/subscription?tab=quota)。
- **Kimi Code 控制台**：开启加油包后，登录 [控制台](https://www.kimi.com/code/console) 查看余额与用量。
- **Kimi Code CLI**：在命令行中输入 `/usage` 直接查询。

## 网页端 Kimi 和 Kimi Code 的加油包是同一个钱包吗？

是的，两端共享同一份加油包额度，充值一次即可通用。

## 加油包、赠送额度和会员额度，先扣哪个？

按额度类型与过期时间决定扣除顺序：

- **过期时间相同**：赠送次数 > 赠送额度 > 订阅/免费额度 > 加油包。
- **过期时间不同**：优先扣除更快过期的额度：
  - 订阅额度最先过期：订阅额度 > 赠送次数 > 赠送额度 > 加油包
  - 赠送次数最先过期：赠送次数 > 赠送额度 > 订阅额度 > 加油包
  - 赠送额度最先过期：赠送额度 > 赠送次数 > 订阅额度 > 加油包
- **加油包不过期**，因此扣除优先级最低；但当你触发频控限制时，可直接消耗加油包余额突破频控（未开启加油包时会引导购买）。

<Callout type="tip">
**举例**：春节期间你通过活动获得了 10 次 Agent 赠送次数，世界杯活动获得了 100 万 token 赠送额度，本月有订阅月度额度，同时自己充值了 50 元加油包。此时扣除顺序为：

- 过期时间相同：春节赠送次数 → 世界杯赠送额度 → 订阅月度额度 → 50 元加油包。
- 订阅月度额度最先过期：订阅月度额度 → 春节赠送次数 → 世界杯赠送额度 → 50 元加油包。
- 春节赠送次数最先过期：春节赠送次数 → 世界杯赠送额度 → 订阅月度额度 → 50 元加油包。
- 世界杯赠送额度最先过期：世界杯赠送额度 → 春节赠送次数 → 订阅月度额度 → 50 元加油包。

无论哪种情况，50 元加油包都因为不会过期而最后扣除。
</Callout>

当多种提示同时满足条件时，额度相关提示（如额度用尽、已切换加油包等）优先于其他提示（如大任务用量提示）展示。

## 达到额度上限或被限流时还能继续吗？

能。开启加油包后不受订阅限额影响，任意额度触顶都会无缝切到加油包余额，任务不中断，且只扣加油包余额、不影响会员额度刷新。

## 没用完的余额能留到下个月吗？

能。余额不过期、可叠加；订阅失效后仍可消费，但失效期间无法充值。

## 加油包支持企业版吗？

暂不支持。

## 加油包充值可以开发票吗？

可以。进入「我的 → 订阅 → 额度和发票 → 账单与发票」，找到对应充值订单，点击【开发票】即可，发票按单笔充值订单开具。详细流程请参阅 [用户如何自助开发票](/membership/membership-invoice)。
