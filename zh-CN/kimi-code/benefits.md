# Kimi Code 权益说明

Kimi Code 是 Kimi 会员权益中的一项服务，为会员提供编程相关的支持和功能，帮助会员在个人开发的过程中更高效地完成编程任务。

Kimi Code 的额度以订阅日为起点**每 7 天自动刷新**，未用完不累积。除了周额度外，还有**每 5 小时的滚动频率窗口**——即使总量充足，短时间请求过多也会触发限流，等窗口滚动后自动恢复。

所有登录设备和 API Key 共享同一套配额：无论从 CLI、VS Code 还是第三方工具发起请求，消耗的都是同一个账户的额度。超过 30 天未活跃的设备会被自动解绑，重新 `/login` 即可恢复。

登录 [Kimi Code 控制台](https://www.kimi.com/code/console) 可随时查看剩余额度与频限状态、管理 API Key 和登录设备。

## 额度刷新

额度按 **7 天** 为一个周期进行刷新：

- 以订阅日 D1 为起点，每 7 天刷新一次。
- 刷新周期为：D1–D7、D8–D14、D15–D21、D22–D28。
- 未用完的额度**不会**累计到下一个周期。

<Callout type="tip">
建议合理规划每周的使用量，充分利用额度。
</Callout>

## 使用范围

Kimi Code 权益适用于以下工具：

| 工具 | 说明 |
| --- | --- |
| **Kimi Code CLI** | Kimi 官方命令行 AI Agent |
| **Claude Code** | Anthropic 的命令行编程助手 |
| **Roo Code** | VS Code 中的 AI 编程插件 |

在其他未列出的平台或工具中使用 Kimi Code 的 API Key，可能会被视为滥用行为，并可能导致权益受限。请在上述支持的工具中使用，以获得最佳体验和保障。

<Callout type="info">
请注意，本权益仅用于个人开发，非用于企业开发场景。如有企业需求，请关注 [Kimi 开放平台](https://platform.kimi.com/)。
</Callout>

## 计费方式

- Kimi Code 的使用**包含在套餐费用中**，无需额外付费。
- 每次调用会消耗 Kimi Code 专属额度，不同套餐包含的额度不同。
- 系统优先消耗获赠额度，再消耗套餐额度。

## 加油包（Extra Usage）

订阅额度用尽后，可用**加油包（Extra Usage）**余额继续发起请求，无需等待额度刷新。仅订阅会员可开启，且**网页端 Kimi 与 Kimi Code 共享同一份加油包额度**（充值一次，两端通用）。完整条款见 [加油包充值协议](https://www.kimi.com/user/agreement/extra-usage-rules-cn)。

### 充值入口

- **从主站充值**：进入 Kimi [订阅页面](https://www.kimi.com/membership/subscription?tab=quota)，滚动至页面底部的「额度加油包」模块 → 选择充值金额 → 完成支付。
- **从 Kimi Code 控制台充值**：当**周额度或 5 小时额度任意一项消耗超过 80%** 时，进度条卡片会出现【加油包购买】按钮，点击即可跳转至 Kimi 订阅页完成购买。

### 开启与管理

打开「额度加油包」开关后，当订阅额度用尽时，系统会自动从加油包余额中扣减。点击模块的「设置」可开启**每月消费上限**、设定本月最多可花费的金额；进度条则实时显示本月加油包的消耗情况。

### 计费与规则

- **计费**：按实际用量扣费——读取与生成的内容越多、任务越复杂，花费越高；余额以人民币显示，费率以平台展示为准。加油包价格近似于 [Kimi 开放平台](https://platform.kimi.com) 的官方 API 价格；用量较大时，升级订阅通常更划算。
- **消耗优先级**：先扣订阅等限时额度，**加油包最后扣**，作为兜底补充；开启后即使订阅额度用尽，也能无缝消耗加油包余额，任务不中断、不报错。
- **限额控制**：可在设置中开启「每月消费上限」，为加油包设定本月最多可花费的金额；不开启则不限额。
- **有效期与叠加**：余额不过期、可叠加；订阅失效后余额仍可继续消费，但失效期间无法再充值，需重新开通订阅后才能充值。
- **退款**：一般不可退款、转让或兑现。

<Callout type="info">
计费示例（仅供感受量级，实际以平台为准）：一次简单请求（如「推荐一首摇滚歌曲」）约 **0.03 元**；一次复杂的多步任务（如「规划一周成都到川西的自驾行程」）约 **1.6 元**。充值限制：单次最低 25 元，每日最多 10 次、累计 3,000 元，余额上限 10,000 元。
</Callout>

### 查询用量

- **Kimi 网页 / App**：设置 → 订阅和发票 → [我的额度](https://www.kimi.com/membership/subscription?tab=quota)。
- **Kimi Code 控制台**：开启加油包后，登录 [控制台](https://www.kimi.com/code/console) 查看余额与用量。
- **Kimi Code CLI**：在命令行中输入 `/usage` 直接查询。

### 加油包常见问题

- **网页端 Kimi 和 Kimi Code 的加油包是同一个钱包吗？** 是的，两端共享同一份加油包额度，充值一次即可通用。
- **加油包和订阅额度谁先扣？** 先扣订阅等限时额度，加油包在所有限时额度耗尽后才作为兜底扣除。
- **达到额度上限或被限流时还能继续吗？** 能。开启加油包后不受订阅限额影响，任意额度触顶都会无缝切到加油包余额，任务不中断，且只扣加油包余额、不影响会员额度刷新。
- **没用完的余额能留到下个月吗？** 能。余额不过期、可叠加；订阅失效后仍可消费，但失效期间无法充值。
- **加油包支持企业版吗？** 暂不支持。
- **注销账户后余额会退回吗？** 请邮件联系 [membership@moonshot.cn](mailto:membership@moonshot.cn) 申请退款。
