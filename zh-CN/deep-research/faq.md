# 深度研究常见问题

## 深度研究卡住了/一直没出结果怎么办？

深度研究会进行大量网页检索、资料验证与推理，界面未及时刷新不代表任务中断。可尝试：

1. 刷新浏览器页面；
2. 暂时离开当前会话（不影响任务执行）；
3. 稍后返回查看，任务仍在后台运行。

若刷新后仍无结果，请检查网络连接是否稳定后再等待片刻。

<Callout type="info">
深度研究通常需要 10–25 分钟。执行期间可离开页面，任务将在后台异步运行，完成后将发送通知。若页面显示异常，请刷新页面，切勿点击「停止输出」。
</Callout>

## 搜索或思考方向出现了错误？

我们发现在极小概率情况下，深度研究会搜索偏离研究主题。

若发现深度研究的搜索方向或推理结论明显偏离预期，可立即点击页面底部「👎」按钮，在弹窗中简要说明「问题类型 + 具体偏差」（如：搜索偏离主题 / 结论与事实不符）。平台将在 1-3 个工作日内完成核查，确认属实时自动退还本次消耗的额度。

**如何减少方向偏差**：

- **聚焦问题范围**：限定时间范围、地域范围和来源类型，避免问题过于宽泛；
- **善用意图澄清环节**：提交问题后 Kimi 会返回意图澄清确认，在此环节明确指出不希望涵盖的方向，补充需要重点关注的维度；
- **保持输入简洁**：若在意图澄清环节输入内容过长、表意混乱，或偏离原始问题，可能导致研究方向跑偏。

## 深度研究的上下文长度是多少？

Kimi-Researcher 的上下文长度（context length）为 **128K tokens**（约 6–10 万汉字），指模型单次能处理的最大 token 数量（包括输入 + 输出）。这意味着它在单次研究任务中可以**参考**大量文本信息，足以支撑复杂、深入的研究分析。但需注意：**生成内容的长度上限通常远小于上下文窗口**。

| 概念 | 含义 | 说明 |
|------|------|------|
| **上下文窗口** | 模型支持的最大 token 上限 | 128K tokens，包含输入和输出 |
| **输入限制** | 单次可发送的参考资料 + 指令长度 | 建议控制在 100K tokens 以内 |
| **输出限制** | 模型单次生成的最大长度 | 通常约 8K–16K tokens，远小于上下文窗口 |

<Callout type="info">
**常见误解**：128K 上下文 ≠ 能一次性输出 128K 内容。输出长度通常为上下文窗口的 1/8 到 1/16。
</Callout>

**为什么会出现"输出不完"？** 当研究报告过长时，模型可能主动截断（达到单次输出上限后停止）、建议续写，或分段输出——这不是故障，而是输出限制的正常表现。若报告未完成，直接回复"继续"或"请完成剩余部分"；复杂研究建议主动要求分章节生成。

**使用建议**：将核心信息置于提示词前后两端（避免"Lost in the Middle"现象）；超长参考资料先提炼摘要，而非全文粘贴；多轮对话及时开启新会话或进行会话总结；主题过于宽泛时拆分为多个子问题分次研究。

## 没有完成任务就扣除了额度？

深度研究同样区分「普通对话」与「执行任务」，选择「深度研究」任务后即按任务类型计费。

- **计费方式**：任务会根据实际 token 消耗扣除额度。深度研究与其他会员功能（含 Kimi Code）共享一个额度池。
- **任务失败退还**：若任务执行失败（未返回有效结果），不会扣除 token 消耗。

在「我的 → 管理 → 订阅」可查看当前会员账户的 Token 额度使用情况。

<Callout type="info">
如需进一步帮助，可通过产品内「👎」反馈通道联系工作人员，或发送邮件至 [support@moonshot.cn](mailto:support@moonshot.cn)。
</Callout>

## 我主动停止了任务，却被扣除了额度？

深度研究一旦启动，系统即调用算力进行检索、验证与推理，资源已被锁定，因此主动点击「停止」或关闭页面均视为已消耗额度。

若页面长时间无更新，建议先刷新浏览器或稍后再查看，避免因误判「卡住」而中断任务。深度研究通常需要 10–25 分钟，执行期间可离开页面，任务将在后台异步运行，完成后将发送通知。

## 深度研究报告无法下载和保存？

深度研究生成两种报告形式，均可保存。

**文字研究报告**

<Frames
  src="./images/deep-research/download-save-01.png"
  alt="下载入口"
/>

点击右上角「下载」或「复制」按钮，支持本地保存或粘贴使用。报告支持导出为 PDF、Word 格式。

**可视化报告**

点击「预览」→「分享」→「复制链接」→ 在浏览器中打开 → 右键「另存为」，可保存为 HTML、PDF 等格式。可视化报告还支持：

- **预览**：点击「预览」，支持切换网页版、手机版两种视图预览；
- **HTML 源代码复制**：点击预览，切换为「代码模式」，支持复制粘贴可视化报告源代码；
- **公开分享**：点击分享，支持获取公开分享链接。
